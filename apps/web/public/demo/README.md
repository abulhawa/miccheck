# Synthetic speech fixture

speech.wav was generated locally using Windows System.Speech speech synthesis on
2026-09-09. It says: “This is a microphone check. I am speaking clearly at a
comfortable distance.” It contains no recorded person or private microphone audio.

This fixture supports reproducible smoke tests and demonstrations. It is not a
representative speech benchmark and does not establish accuracy across devices,
speakers, accents, rooms, or background conditions.
